# Project Testing

## Testing Objective

The system is tested to verify that student, course, enrollment, automation, security, and reporting features work correctly.

## Test Cases

| Test Case | Expected Result |
|---|---|
| Create Student | Student record is created successfully |
| Create Course | Course record is created successfully |
| Create Enrollment | Enrollment record is created successfully |
| View Student Details | Correct student information is displayed |
| View Course Details | Correct course information is displayed |
| Run Flow | Automation works as configured |
| Check User Permissions | Users can access only permitted records |
| Open Reports | Correct enrollment information is displayed |
| Open Dashboard | Required data is displayed correctly |

## Testing Result

The configured Salesforce components are tested to ensure that the system functions according to the defined requirements.
