# Brainstorming & Ideation

## Project Title
Student Enrollment & Course Management System

## Problem Statement
Managing student, course, and enrollment information manually can be time-consuming and difficult to maintain.

## Proposed Solution
A Salesforce-based system to manage student details, courses, and enrollments in an organized and efficient way.

## Target Users
- Admin
- Enrollment Officer
- Instructor

## Key Features
- Student Management
- Course Management
- Enrollment Management
- Automation
- Reports and Dashboards
- Role-based Security
